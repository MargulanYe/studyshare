# Privacy and Data Security

## Data minimization
StudyShare stores only a username, an e-mail address and a hashed password. It uses no advertising or third-party tracking tools.

## Security measures
- Passwords are hashed with a modern algorithm (bcrypt/argon2).
- All connections use HTTPS.
- Access to the database is limited to maintainers.

## User rights
Users can export or delete their account and all personal data at any time from their profile settings.

## Data breach plan
If a breach is detected, maintainers will fix the vulnerability, reset affected passwords and notify affected users within 72 hours.
