# Contributing to StudyShare

Thank you for helping! Everyone is welcome.

## Getting started
1. Fork the repository and clone your fork.
2. Follow [docs/installation.md](docs/installation.md) to run the project locally.
3. Create a branch: `git checkout -b feature/short-description`.

## Making changes
- Keep changes small and focused.
- Follow the existing code style and write clear commit messages.
- Update the documentation if behavior changes.

## Opening issues
Describe the problem, steps to reproduce, and what you expected. Use the labels `bug`, `feature` or `question`.

## Pull requests
1. Push your branch and open a pull request against `main`.
2. Describe what you changed and why; link the related issue.
3. A maintainer will review it. Please respond to feedback.

## Code of Conduct
By participating you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
